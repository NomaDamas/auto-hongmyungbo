# X-growth-skills

一套面向 X（Twitter）创作者的实战 Agent Skills：从账号定位、主页搭建和冷启动，到内容生产、推荐算法、互动增长、数据复盘与变现。

本仓库不是“爆款公式”合集，也不承诺每条内容都获得高曝光。它把多位 X 创作者的实战经验、X 官方创作建议和公开算法资料，蒸馏成 15 个可独立调用、可组合使用、带适用边界的 skills。

## 这套 skills 能解决什么问题

- 新账号不知道如何定位、装修主页和完成冷启动
- 内容发了没人看，不知道问题出在选题、结构、互动还是主页转化
- 想把 AI 工具、开源项目和行业资讯写成值得收藏的内容
- 想理解 For You 推荐机制，而不是依赖流量玄学
- 想系统研究对标账号，找到差异化内容方向
- 想用数据复盘内容，并规划可持续的变现路径

## 如何使用

克隆仓库：

```bash
git clone https://github.com/kangarooking/X-growth-skills.git
cd X-growth-skills
```

将需要的 skill 目录复制到你的 Agent skills 目录。例如：

```bash
# Claude Code
cp -R x-account-setup ~/.claude/skills/
cp -R x-cold-start-playbook ~/.claude/skills/

# Codex
cp -R x-account-setup ~/.codex/skills/
cp -R x-cold-start-playbook ~/.codex/skills/
```

也可以直接把整个仓库交给支持 Agent Skills 的工具，并要求它按 `SKILL.md` 的触发条件选择合适的 skill。

示例问题：

```text
请用当前目录的 skills 分析我的 X 账号定位和主页。

我写完了一条推文，请检查它是否具备价值承诺、使用场景、入口、证据和收藏理由。

这是我过去 30 天的 X 数据，请按内容类型做 80/20 复盘。
```
