## 风险与改进建议

1. **should-trigger-02 英文触发**: 当前 description 含英文 trigger 词("announcement tone / helpful expression / show don't tell")，但英文场景的实际触发准确率需独立盲测验证。建议后续用英文 sub-agent 重测。

2. **edge-01 过度翻译风险**: 当初稿部分已是外部语言时，agent 可能仍执行完整翻译流程。E 步骤 1 的判停条件已覆盖此场景，但实际执行中 agent 是否会正确判停需验证。建议在 E 步骤 1 中更明确地写"若超过 70% 内容已是外部语言，仅标记需翻译的部分"。

3. **与 x-five-piece-checklist 的边界**: 两个 skill 都涉及"证据"概念。三次翻译的第三次(结论→证据)和五件套的第4件(证据)有重叠。当前靠"检查 vs 改写"区分，但在实际使用中用户可能同时需要两者。建议在阶段 3 建立 composes-with 关系。

4. **fallback 可信度**: 本次为自测，所有 case 由主流程自行评估，存在自我合理化风险。特别是 should_not_trigger 的 3 条诱饵，自评"通过"可能偏低估了实际混淆概率。**强烈建议**后续用独立 sub-agent 盲测重跑，尤其是跨 skill 诱饵部分。
